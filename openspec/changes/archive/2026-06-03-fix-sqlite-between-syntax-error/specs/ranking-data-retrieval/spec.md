## 追加要件

### 要件: SQLite BETWEEN 句の正しい構文

システムは、適切な日付範囲フィルタリングを確保するために、BETWEEN 句で正しい SQLite 構文を使用しなければならない。

#### シナリオ: 公式ランキングデータの日付範囲検索

- **WHEN** BETWEEN を使用して特定の日付範囲内のランキングデータをクエリするとき
- **THEN** SQL クエリは BETWEEN 条件の前に正しいカラム名を含まなければならない
- **AND** クエリは 集計日 が @Date2 と @Date1 の間にあるレコードを正しくフィルタリングしなければならない

### 要件: フォールバッククエリの構文修正

システムは、プライマリクエリが結果を返さない場合のフォールバッククエリで、正しい SQLite 構文を使用しなければならない。

#### シナリオ: フォールバックランキングデータ検索

- **WHEN** プライマリ日付範囲クエリが結果を返さないとき
- **THEN** フォールバッククエリは BETWEEN 条件の前に正しいカラム名を含まなければならない
- **AND** クエリは代替クエリロジックを正しく処理しなければならない
