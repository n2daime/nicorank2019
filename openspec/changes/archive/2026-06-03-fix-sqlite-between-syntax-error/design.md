## コンテキスト

nicorankLib\Analyze\Official\RankingHistory.cs の RankingHistory::GetRankingSabunDataLogOfficial メソッド内で、NicoChart.Ranking テーブルへのフォールバッククエリに SQL 構文エラーがあります。BETWEEN 句の前にカラム名（集計日）が欠落しているため、SQLite で構文エラーが発生します。

## 目標 / 非目標

**目標:**
- BETWEEN 句の前に不足しているカラム名を追加して SQL 構文エラーを修正
- 既存の機能とクエリロジックを維持
- 日付範囲クエリのパラメータバインディングを適切に維持

**非目標:**
- アルゴリズムやデータフローの変更
- データベーススキーマやテーブル構造の変更
- 構文修正以外の新機能追加

## 決定事項

**決定: BETWEEN 句の前にカラム名（集計日）を追加**
- **理由**: SQLite の BETWEEN 構文では、BETWEEN の前にカラム名が必要です。現在のコードでは `and BETWEEN` のようにカラム名が欠落しています。
- **代替案**: クエリを `>=` と `<=` を使用した別の条件に書き換えることも検討しましたが、クエリ構造を不必要に変更することになります。
- **採用理由**: 元の意図とロジックを維持しながら、構文エラーのみを修正する最小限の変更です。

## リスク / トレードオフ

- **リスク**: 構文修正後にパラメータバインディングに問題がある場合、クエリが誤った結果を返す可能性
- **対策**: パラメータ (@ID, @Date1, @Date2) は正しく、変更不要であることを確認済み
- **トレードオフ**: 純粋な構文修正のため、重要なトレードオフはありません
